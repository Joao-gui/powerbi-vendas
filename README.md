# Dashboard de Vendas - Power BI

Projeto desenvolvido para análise de vendas utilizando Power BI.

## Objetivos
- Analisar faturamento
- Identificar produtos mais vendidos
- Avaliar evolução mensal

## Tecnologias
- Power BI
- Power Query
- DAX

## Métricas
- Receita total
- Ticket médio
- Quantidade vendida
